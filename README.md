# Cursos e Estudos

Este repositório reúne códigos, exercícios práticos e atividades desenvolvidas durante minha trajetória de aprendizagem em programação.

O objetivo é documentar minha evolução técnica, consolidar conhecimentos adquiridos e manter organizados os conteúdos estudados em diferentes plataformas educacionais.

## Plataformas de estudo

- **FreeCodeCamp:** cursos, certificações e exercícios práticos de programação.
- **EBAC:** atividades e práticas desenvolvidas durante os cursos.
- **YouTube:** exercícios e códigos desenvolvidos a partir de conteúdos educacionais.
- **Udemy:** projetos e atividades desenvolvidos durante cursos da plataforma.

## Organização

Os arquivos estão organizados por plataforma, curso, linguagem de programação e conteúdo estudado.

## Tecnologias

As tecnologias utilizadas serão adicionadas conforme forem estudadas e aplicadas nos exercícios e projetos.

## Objetivo

Construir uma base sólida em programação, desenvolver raciocínio lógico e acompanhar minha evolução como estudante de Ciência da Computação.
