# FreeCodeCamp

Este diretório reúne os estudos, exercícios práticos e projetos desenvolvidos durante os cursos e certificações oferecidos pela plataforma FreeCodeCamp.

## Objetivo

Registrar o aprendizado adquirido por meio dos conteúdos educacionais e das atividades práticas propostas pela plataforma.

## Cursos e certificações

- Python

## Organização

Os conteúdos estão separados por curso, linguagem de programação e módulos de aprendizagem.

Cada diretório contém os respectivos códigos, exercícios e atividades desenvolvidos durante os estudos.

## Tecnologias

- Python

## Plataforma

[FreeCodeCamp](https://www.freecodecamp.org/)
