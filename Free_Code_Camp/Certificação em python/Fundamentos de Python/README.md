# Fundamentos de Python

Este diretório contém exercícios e laboratórios desenvolvidos durante o estudo dos conceitos fundamentais da linguagem Python na certificação do FreeCodeCamp.

## Conteúdos praticados

- Variáveis e tipos de dados
- Operações matemáticas
- Manipulação de strings
- Estruturas condicionais
- Funções
- Lógica de programação

## Exercícios e laboratórios

Entre as atividades desenvolvidas estão:

- Divisor de conta
- Planejador de clima para viagens
- Rastreador de inventário de cozinha
- Calculadora de reserva de ingresso de cinema
- Impressora de boletim escolar
- Gerador de perfil de funcionário
- Validador de perfil de funcionário
- Cifra de César
- Aplicação de descontos
- Criação de personagem RPG

## Objetivo

Praticar os fundamentos da linguagem Python, desenvolver o raciocínio lógico e adquirir experiência na resolução de problemas por meio da programação.
