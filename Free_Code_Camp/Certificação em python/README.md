# Certificação em Python

Este diretório reúne os exercícios, laboratórios e projetos desenvolvidos durante meus estudos de Python na plataforma FreeCodeCamp.

## Objetivo

Desenvolver e consolidar conhecimentos na linguagem Python, praticando conceitos fundamentais de programação por meio de atividades práticas.

## Conteúdos estudados

- Fundamentos de Python
- Variáveis e tipos de dados
- Operadores e expressões
- Estruturas condicionais
- Laços de repetição
- Sequências e coleções
- Funções
- Outros conceitos abordados ao longo da certificação

## Organização

Os exercícios estão separados de acordo com os módulos e conteúdos da certificação.

## Tecnologia utilizada

- Python 3

## Plataforma

[FreeCodeCamp](https://www.freecodecamp.org/)
