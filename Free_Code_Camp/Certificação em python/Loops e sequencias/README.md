# Loops e Sequências

Este diretório reúne exercícios e atividades práticas relacionados a estruturas de repetição e manipulação de sequências na linguagem Python.

## Conteúdos estudados

- Estrutura de repetição `for`
- Estrutura de repetição `while`
- Iteração sobre sequências
- Listas e operações
- Controle de repetição
- Utilização de loops na resolução de problemas

## Objetivo

Compreender o funcionamento das estruturas de repetição e desenvolver habilidades para trabalhar com sequências de dados, automatizando tarefas por meio da programação.

## Tecnologia utilizada

- Python 3
