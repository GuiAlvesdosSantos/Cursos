# Estudos pelo YouTube

Este diretório reúne códigos e exercícios desenvolvidos a partir de aulas, tutoriais e conteúdos educacionais encontrados no YouTube.

## Objetivo

Complementar os estudos de programação por meio de diferentes fontes de conhecimento, colocando em prática os conceitos apresentados nos conteúdos acompanhados.

## Organização

Os materiais estão organizados de acordo com as linguagens de programação, cursos ou conteúdos estudados.

## Atividades

- Exercícios de programação
- Práticas de lógica de programação
- Implementações acompanhadas de tutoriais
- Pequenos experimentos e aplicações

## Observação

Os códigos deste diretório possuem finalidade educacional e são utilizados para praticar e consolidar conhecimentos.
